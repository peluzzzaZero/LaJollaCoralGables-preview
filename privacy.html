Privacy

To arrange a visit, use the Microsoft Bookings calendar. You can also contact La Jolla directly by phone or email.

What else this page does

Opening the map link leaves this site only when you choose it. This site's typefaces are hosted locally.

Visit appointments

When you open the visit calendar, Microsoft Bookings loads in this page or in a new tab. Microsoft processes the appointment details you enter for La Jolla to manage visits and send booking notifications. The calendar may load its own resources. A visit appointment does not reserve a space for an event.

Privacidad

Para agendar una visita, use el calendario de Microsoft Bookings. También puede contactar directamente con La Jolla por teléfono o correo.

Qué más hace esta página

El enlace del mapa sale de este sitio solo cuando usted lo abre. Las tipografías de este sitio están alojadas localmente.

Citas para visitas

Al abrir el calendario de visitas, Microsoft Bookings se carga dentro de esta página o en una pestaña nueva. Microsoft procesa los datos de la cita que usted introduce para que La Jolla gestione las visitas y envíe avisos de reserva. El calendario puede cargar sus propios recursos. Una cita de visita no reserva un espacio para un evento.
