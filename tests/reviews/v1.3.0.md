# Review — v1.3.0

The previous patch addressed only text corrections and did not implement the new photo/video delivery. This cycle corrects that omission with visible venue media, preserving the user's approved elegance and commercial inquiry flow.

Selection: actual facade in the opening, wide facade on the venue path, empty ballroom as the main interior view, staircase/music/garden details and a second ballroom angle. No unconfirmed room name is assigned to those photos. The promotional collage is unsuitable as a photographic scene; the decorated event photo remains unverified and is not presented as venue evidence.

The two portrait films retain their authentic framing and duration, with audio removed, orientation normalized and delivery bounded to 480 px/24 fps. H.264 is accompanied by a VP9/WebM alternative for browsers without H.264 decoding. Poster frames come directly from each video. Native controls and file links work without page JavaScript; preload=none and no autoplay prevent initial video transfer or unsolicited motion. Playback pauses off screen, in a hidden page and when the other film starts.

Required verification covers bilingual responsive geometry, actual decoded playback, single-player behavior, off-screen pause, metadata orientation, blocked video fallback, no-JavaScript controls and native interior disclosure, plus all existing service/inquiry/error/keyboard checks. CI repeats the suite before both integrations and release creation.
