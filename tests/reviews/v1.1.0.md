- Sending the visitor directly to the form after every service prevented assembling a selection. Choices now stay in the catalog; a clear continue action carries them into the inquiry.
- The initial summary put its continue action below the selected list. Visual review moved it above the list for easier access, especially on mobile.
- Native controls made the inquiry grid 48 px too wide at 320 px. Grid children and controls now shrink to the available column. Explicit 320/375 px checks cover the fields and menu; the narrow header keeps the brand name on one line.
- Screenshots taken during native smooth scrolling could capture an unsettled fixed layer. Evidence now waits for scroll position to settle and checks the header's viewport position.
- Missing page JavaScript could leave a default form submission available. Submit and service buttons start disabled; successful script initialization enables them. JavaScript-disabled contact alternatives and direct email/phone links remain available.
- Decorative arrow glyphs were missing in the review environment's font fallback. They are drawn with CSS strokes instead.
