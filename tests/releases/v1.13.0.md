# La Jolla v1.13.0

Prepare native inquiries for the GoDaddy Node preview: use its hosted MySQL, store requests before sending, claim delivery atomically, preserve idempotency and uncertain attempts across restarts, and protect throughput. Create only versioned La Jolla tables with separate allowlisted preview/live namespaces; existing tables are not changed. Credentials come from the platform's five DB environment variables and are never served.

The private `/admin/mail` setup is opt-in and requires a private setup password, same-origin actions, CSRF protection and owner-confirmed storage and technical receipt. It supports GoDaddy's built-in transactional gateway or Microsoft browser authorization bound to the business mailbox. Microsoft uses signed identity validation, PKCE, state/nonce, Mail.Send and profile-only User.Read, encrypted persisted OAuth tokens and refresh rotation; no mailbox password, device-code login, Exchange PowerShell, message-reading or calendar permission. The GoDaddy gateway uses its documented fixed loopback helper and the platform sender, with a fixed configured business recipient and visitor Reply-To. These modes are distinct; changing provider cannot reuse the other's accepted technical test.

Both Node-served forms now use the same-origin API and never fall back to Web3Forms. Static GitHub Pages retains its legacy transport until migration. Written fields remain after failure; unchanged retries reuse the same in-memory request UUID, and uncertain results show their saved reference without claiming delivery or booking. The film timeline, approved photos and layout are unchanged.

Native public sending and private setup remain disabled by default. No real mail or business database access was performed by automated checks. Actual hosted configuration, storage persistence, the chosen provider and marked inbox receipt must be verified before enabling public inquiries. The old production site/domain/DNS and bookings are unchanged. The gateway documentation does not establish unlimited email or pricing; do not claim that.
