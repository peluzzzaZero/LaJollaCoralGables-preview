# v1.17.0 — the visit stays within the house

Every visit action on the homepage and legal pages opens the existing Microsoft Bookings calendar over the current page. Native new-tab gestures and the direct Bookings URL remain useful without JavaScript. Closing the calendar preserves the film position and the unfinished calendar session; reader actions return focus to their visible disclosure.

The contact footer now belongs to the film frame alongside the chapter controls. Phone, email, venue address, management identity and legal links remain available in an opaque, scrollable contact panel. The narrowest phones use the scene number rather than a clipped chapter caption. Static/reduced-motion alternatives retain a native contact disclosure within the house section.

Guest experiences appear within the occasions view and Facebook posts within the team view, using the owner-confirmed La Jolla Ballroom profile and Google Maps place. Facebook's timeline is requested only after an explicit action, with a permanent source link. Google reviews use the official Places JavaScript API only when a restricted browser key has been configured and the visitor requests them. The selection includes only attributed five-star reviews, retains original text, dates and individual source links, and describes its relevance order. It does not invent reviews, compute a misleading overall rating, or persist review content in browser storage or a generated public cache. Instagram/TikTok accounts were not verified and are not guessed.

Google review activation requires the owner's existing Maps/Places account configuration; without it the review-source link remains usable and no API is called. The public browser key must be restricted to approved website referrers and Maps/Places APIs, with billing/quota limits managed by the owner. It is deliberately browser-visible and must never be replaced with a private server credential. No purchase, new billing account, real booking or mail is performed by this release. Optional providers' policies are linked in the bilingual privacy/terms pages.

Checks exercise the reviewed public package, keyboard/focus/scroll continuity, in-frame contact across all nine chapters, EN/ES phone/tablet/desktop layouts, the original motion and reader regressions, no-JS fallbacks, and isolated social-provider responses including unavailable data, negative ratings and unsafe links. Exact-head external review, complete CI, immutable tag and final public publication evidence belong in the feature/release PRs. Real-device iOS and the successful live activation of unconfigured Google reviews are not claimed.
