# v1.34.3 — the chat keeps answering when the person check cannot run

On 29 October 2026, with Cloudflare Turnstile switched on in the assistant for a short controlled test, the chat on lajollacoralgables.com answered "Sorry, something went wrong": the check failed inside the browser (Turnstile client error 600010) before any token existed. Turnstile was switched off again at once.

1. `chat.js` is the assistant's widget at commit e7fc857. When the person check cannot run in the visitor's browser (error, expiry, unsupported browser, blocked script), the message is sent again marked "unavailable" instead of ending in an error. Later messages on the same page skip the check that already failed.
2. The assistant answers such messages only from its fixed rules and cards, with no AI call, so nobody can spend the AI quota without passing the check. A check that never answers still ends after 20 s with the calendar help.
3. `tests/browser/chat.py` checks that a failed check and a blocked Turnstile script are answered, that both messages are marked "unavailable" and that Turnstile is rendered only once; `tests/visit-cta.test.mjs` pins the new copy by hash.

Verification for this release: `npm run build && npm test`; the Chromium browser suites run locally before pushing (CI also runs WebKit); assistant tests (194) and a local browser run against the real assistant with the Turnstile script blocked and with a simulated 600010 error; external review (Claude CLI, Sonnet/high) of the PR head.

Order: the assistant change (lajollaAsistente e7fc857, which accepts "unavailable" and never calls a model for it, whatever client sends it) was deployed to Cloudflare before this release; Turnstile is switched on only after this release is live.

Limitations: once a check fails, later messages on that page stay without AI until the page is reloaded. The cause of the 600010 error on the public site is not yet known; this release makes the chat robust to it. Turnstile stays off in the assistant until a short test on the public site after this release.

Next: switch Turnstile on, test on the public site from a normal browser and a phone.
