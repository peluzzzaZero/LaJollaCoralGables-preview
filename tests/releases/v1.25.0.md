# v1.25.0 — the house's own lettering, and photographs that arrive

The owner asked for the name "La Jolla" to be written the way the house's own brochure writes it, then for the same lettering on the titles, and for the section photographs to appear with a subtle effect.

1. Name lettering — the brochure lockup ("La Jolla" in a flowing copperplate script over "CORAL GABLES" in spaced capitals) is text converted to outlines in the PDF, so it carries no font name. The script outlines are taken directly from the brochure as a 16 KB vector (`assets/brand/la-jolla-script.svg`), so the letters are the brochure's own rather than a look-alike font.
2. Where the name appears as the name — header (every page), the opening title, the location card and the footer — it is drawn with that lettering through a CSS mask, in the same color as before. The words stay in the page as real text for screen readers, translation and search. "Coral Gables" already uses spaced serif capitals like the brochure and is unchanged. Body text and sentences that mention La Jolla keep the current fonts. A print and Windows high-contrast fallback shows the plain words, and the vector is preloaded.
3. Chapter titles — every chapter title on the home page (and the tour's script line) uses Great Vibes, the closest free match to the brochure's title script, self-hosted with its OFL licence (55 KB WoFF2, Latin and Spanish accents). The tour's step numerals stay in the serif for readability. Body text, eyebrows and small headings are unchanged.
4. Photographs — section photographs (the hall, the Lexington mark, the Instagram tiles, the team portraits and the façade card) rise gently from a soft veil the first time they enter the screen, with a slight stagger across the tile rows. They never start fully hidden, and nothing moves with reduced motion, save-data or without JavaScript. Existing reveals, parallax and the album scenes are unchanged.

No new video, generated media, scripts or trackers. No banned wording and no prices.

Release gate (results recorded in the feature and release pull requests): the static/content suite including a new lettering test, browser screenshots before and after on mobile and desktop, an external Sonnet/high review of the exact head, and complete CI.

Limitations: the brochure's typeface could not be named because its text is outlined. The name uses the brochure's exact outlines; the titles use the closest free script, which is similar but not identical. Provenance is in `assets/brand/la-jolla-script.source.json`.

Next useful improvement: photographs of the house for the tour chapter, and the assistant the owner described, once its brief arrives.
