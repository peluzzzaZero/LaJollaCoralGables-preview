# v1.25.0 — the name, in the house's own lettering

The owner asked for the name "La Jolla" to be written the way the house's own brochure writes it, and only the name; the rest of the typography stays as it is.

1. Name lettering — the brochure lockup ("La Jolla" in a flowing copperplate script over "CORAL GABLES" in spaced capitals) is text converted to outlines in the PDF, so it carries no font name. The script outlines are taken directly from the brochure as a 16 KB vector (`assets/brand/la-jolla-script.svg`), so the letters are the brochure's own rather than a look-alike font.
2. Where the name appears as the name — header (every page), the opening title, the location card and the footer — it is drawn with that lettering through a CSS mask, in the same color as before. The words stay in the page as real text for screen readers, translation and search. "Coral Gables" already uses spaced serif capitals like the brochure and is unchanged. Body text, headings and sentences that mention La Jolla keep the current fonts.

No new video, generated media, scripts or trackers. No banned wording and no prices.

Release gate (results recorded in the feature and release pull requests): the static/content suite including a new lettering test, browser screenshots before and after on mobile and desktop, an external Sonnet/high review of the exact head, and complete CI.

Limitations: the lettering comes from the owner's brochure; the original typeface could not be named from the PDF because its text is outlined.

Next useful improvement: photographs of the house for the tour chapter, and the assistant the owner described, once its brief arrives.
