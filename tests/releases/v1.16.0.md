# La Jolla v1.16.0

Add a venue-tour calendar to the planning page using the business-owned Microsoft Bookings link. The existing inquiry remains an event quote request. Its preferred date never becomes a confirmed event-space reservation. A discreet tour invitation beside the form and a second link after successful inquiry submission open a native modal, with Microsoft loaded only on request. An ordinary new-tab link works without JavaScript and remains available if embedding fails.

Keep the entered inquiry, selection, scroll position and an unfinished calendar session when the modal closes. Translate its controls and explanations into English and Spanish; Microsoft owns its calendar interface and appointment confirmations. Closing or loading the calendar never changes inquiry delivery or confirms a reservation locally.

No automatic joining of inquiries and appointments, calendar-space inventory, Graph permission changes, or certification of notification email receipt. Three owner-configured Power Automate flows still require individual delivery tests. No production DNS or GoDaddy Live deployment.
