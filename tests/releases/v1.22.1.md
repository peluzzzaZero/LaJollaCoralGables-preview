# v1.22.1 — the location map opens Google Maps at La Jolla

The owner reported from his phone that the Location chapter's map showed the whole world without marking La Jolla, needed a tap to open and misbehaved once open. The keyless Google embed (`google.com/maps?q=…&output=embed`) is unofficial; with the venue name in the query it did not resolve the place, so it fell back to a world view. It was only ever tested against an intercepted request.

Fix: the chapter no longer embeds a map. The facade photograph is now one link card, "Open in Google Maps", that opens Google Maps in a new tab through the official Maps URL with La Jolla's Place ID (ChIJWbeTzJu32YgRbGDUdwzI0W0) and its address, so the venue is marked. "Get directions" (Place ID destination) and "Open in Apple Maps" are unchanged. Nothing from Google loads inside the page; the privacy page says so.

Tests: the static suite fails if a keyless embed or an iframe returns, or if the card loses the Place ID or address; the browser test checks in Chromium and WebKit that the card has a real height, receives taps at its centre, opens in a new tab and loads nothing from Google.

No new video, generated media, scripts or trackers.

Release gate (results recorded in the feature and release pull requests): the static/content suite, the browser review in EN and ES, an external Sonnet/high review of the exact head, and mobile and desktop screenshots.
