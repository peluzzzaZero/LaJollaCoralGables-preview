# v1.22.1 — the location map opens Google Maps at La Jolla

The owner reported from his phone that the Location chapter's map showed the whole world without marking La Jolla, needed a tap to open and misbehaved once open. The keyless Google embed (`google.com/maps?q=…&output=embed`) is unofficial and takes no Place ID; the owner's screenshot shows it falling back to a world view. Why it did not resolve the address is inferred, not reproduced: this environment cannot reach Google, and the embed was only ever tested against an intercepted request.

Fix: the chapter no longer embeds a map. The facade photograph is now one link card, "Open in Google Maps", that opens Google Maps in a new tab through the official Maps URL with La Jolla's Place ID (ChIJWbeTzJu32YgRbGDUdwzI0W0) and its address, so the venue is marked. "Get directions" (Place ID destination) and "Open in Apple Maps" are unchanged. Nothing from Google loads inside the page; the privacy page says so.

Tests: the static suite fails if a keyless embed or an iframe returns, or if the card loses the Place ID or address; the browser test checks in Chromium and WebKit that the card has a real height and receives taps at its centre, that nothing on google.com is requested before the card is clicked, and that clicking it opens a new tab at the Place ID URL (Google intercepted) while the site stays open.

No new video, generated media, scripts or trackers.

Verification: static suite, browser review in EN and ES (Chromium locally, Chromium and WebKit in CI), an external Sonnet/high review of the exact head, and mobile and desktop screenshots, recorded in the feature and release pull requests.

Limitations: no test opens the real Google Maps; that the Place ID URL marks La Jolla relies on Google's documented Maps URLs and should be confirmed by opening the card on a phone after publication. The card no longer previews a map, only the facade photograph.

Next useful improvement: once the owner's restricted Google browser key is active, a proper Maps JavaScript map pinned by Place ID could return inside the page, loaded only on request.
