# v1.27.1 — a clean title on the visit page

The weekly visual check of v1.27.0 found that the visit page (`planning.html`) opened with a focus ring drawn around its title, "Come see the house": black on desktop Chrome, gold on mobile. The page moves focus to the title on load so screen readers start there, and browsers draw a focus ring for focus that no pointer caused.

1. The title keeps receiving focus on load (screen readers still announce it first), but no outline is drawn for it. The title is not a control and is not in the tab order, so keyboard users never reach it with Tab; links, buttons and form fields keep their visible `:focus-visible` ring.

No content, media, layout or behaviour changes besides that outline.

Verification: static suite (the rule is scoped to the visit page title and the global `:focus-visible` rule for controls is unchanged), browser screenshots of the visit page at 1920 and 390 on load, Tab from load still shows the ring on the first control, external Sonnet/high review of the exact head, recorded in the feature pull request (#95) and the release pull request.
